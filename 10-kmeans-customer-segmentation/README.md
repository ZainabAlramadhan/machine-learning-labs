# Lab 10: Credit Card Customer Segmentation (K-Means)

**Course:** ARTI308 Machine Learning | **Type:** Unsupervised learning | **Tools:** Python, Scikit-learn

## Objective
Group credit card customers by usage behavior using K-Means clustering.

## Dataset
Customer-level credit card usage data: balance, purchases, cash advance, payments, tenure, and more ([source](https://www.kaggle.com/datasets/arjunbhasin2013/ccdata/data)).

## What I Did
- Cleaned and scaled the data
- Chose the number of clusters and applied K-Means
- Interpreted each customer segment
