# Machine Learning Labs

Labs from my Machine Learning course (ARTI308) at Imam Abdulrahman Bin Faisal University. They cover the full workflow, from data cleaning and exploration to supervised and unsupervised models. Each lab has its own folder with a notebook, dataset, and write-up.

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter, Google Colab

## Skills Demonstrated
- Data cleaning and preprocessing on real-world datasets
- Exploratory data analysis and visualization
- Training and evaluating regression, classification, and clustering models
- Model selection and hyperparameter tuning
